# 📚 Library Management System

A Library Management System built with Java and SQLite that helps manage books, users, borrowing operations, and overdue notifications efficiently.

---

# ✨ Features

- 📖 Add, update, delete, and search books
- 👤 Manage library users
- 🔄 Borrow and return books
- ⏰ Track overdue books
- 📧 Send email notifications for overdue books
- 🗄️ SQLite database integration
- 🔐 Environment variables using Dotenv
- 🖥️ Clean and organized Java project structure

---

# 🛠️ Technologies Used

- Java
- SQLite
- JDBC
- Dotenv
- IntelliJ IDEA
